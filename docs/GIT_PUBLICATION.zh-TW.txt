下載與建置
  Git 原始碼下載不包含 dist 預建產物；在專案根目錄執行：
    python3 scripts/build.py
  需要既有 Guacamole 1.6.0；scripts/install.sh 安裝的是主題管理 CLI。
  不會自動複製原部署的帳號、設備、密碼或網路設定，也不是完整系統備份。
  完整核心繁中 JAR 仍由部署者另行提供；本專案含 GTM 與 JDBC 補充翻譯。
